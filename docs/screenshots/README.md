# Screenshots

Pictures of what was built, kept here because Freelancer chat attachments do not
always open. GitHub shows a PNG in the browser as soon as you click it, so this
folder is the reliable place to look at anything I have taken a picture of.

Named by the date and what they show. Nothing here is used by the site - the
deploy script only copies `src`, `templates`, `public`, `migrations` and
`config`, so this folder never reaches the server.
